# Java DSA Series: Algorithm & Data Structure Implementation

This repository serves as a structured workspace for implementing Data Structures and Algorithms (DSA) in Java. The architecture strictly follows industry-standard packaging and object-oriented principles.

## ⚙️ Tech Stack & Environment
* **Language:** Java
* **IDE:** IntelliJ IDEA
* **Version Control:** Git / GitHub
* **Build Architecture:** Package-driven module isolation

## 🏗️ Project Architecture
The repository is modularized into strictly defined namespaces to prevent collision and ensure high cohesion:

```text
src/
└── com/rahul/dsa/
    ├── basics/         # Primitives, Conditionals, Loops
    ├── patterns/       # Matrix/Pattern Printing Logic
    ├── fundamentals/   # Methods, Basic Math for DSA
    ├── oops/           # Encapsulation, Inheritance, Polymorphism
    ├── arrays/         # 1D/2D Arrays, Prefix Sum, Kadane's Algorithm
    └── algorithms/
        └── sorting/    # O(N^2) and O(N log N) Sorting Algorithms
        ├── searching/  # Binary Search, Search Space Optimization
